# KI Perspektiven

KI Perspektiven ist eine deutsch- und englischsprachige Website für Unternehmen und Fachleute, die sich mit dem Einsatz von künstlicher Intelligenz beschäftigen. Sie bietet Themenseiten und Blogbeiträge zu KI in der Datenanalyse und Softwareentwicklung. Mit dem interaktiven KI-Audit können Unternehmen ihren KI-Reifegrad in acht Bereichen selbst einschätzen.
